# nds-da-tmpe

Nominal Device Support driver for interfacing with the TEWS TMPE627 for data acquisition and processing through the NDS-DA module (using ChimeraTK DeviceAccess).

Requirements:

- [NDS-DA](https://github.com/ndsv3/nds-da)
- TMPE627 FWK Design: TODO
